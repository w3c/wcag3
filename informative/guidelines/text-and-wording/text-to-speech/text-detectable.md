## Tests

<b>Procedure</b>
For all visible text: 
1. If the text is embedded in an image, check that the text has a :term[text alternative] or can be accurately read using the :term[accessibility support set].
2. If text content, check that the text is not hidden using code such as the `aria-hidden` attribute.

<b>Expected results</b>
* #1 and #2 are true.
