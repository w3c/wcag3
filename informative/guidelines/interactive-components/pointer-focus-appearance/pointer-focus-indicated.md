## Methods

- Interactive elements are highlighted when the pointer is on the element. 
  For example, a set of image links are shown, and the one under the pointer is highlighted with an outline or change in size.

## Tests

<b>Procedure</b>

With appropriate user settings enabled:
1. Move the pointer (mouse, eye tracker, hand gesture in VR space, …).
2. Check that there is some form of indication of where the user is pointing to.

<b>Expected results</b>
- #2 is true.
