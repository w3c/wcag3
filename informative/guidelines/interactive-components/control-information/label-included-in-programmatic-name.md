## Methods

- Code the same name as you display.

## Recommended Practices

- Use unique names and keep the programmatic and visual names the same.

## Tests

<b>Procedure</b>

For each interactive element:

1. Identify the interactive elements' programmatic name. 
2. Identify the interactive element's visual name.
3. Check that #1 includes all of #2.

<b>Expected results</b>
- #3 is true.
