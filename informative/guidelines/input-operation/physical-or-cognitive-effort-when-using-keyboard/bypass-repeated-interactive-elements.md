## Tests

### Procedure

For each primary section of content on a :term[page]/:term[view]:

1. Position :term[keyboard focus] at a location that is not at the start of the section.
2. There is a mechanism for moving focus to the start of the section.
3. Invoking the mechanism moves focus to the first element in the section or to the section element itself.
4. Repeat to ensure the functionality works for initial locations before, after, and inside the section.

### Expected results

* #2 and #3 are true.
