  - functionality

set of capabilities provided to users by the :term[content] that are operable via at least one input modality

:::note
Content may provide multiple ways of delivering the same capability.

For example, a “spin button” often provides multiple ways for a user to input a number:

- A text field that accepts direct entry of a numeric value
- An increment button that adds 1 to the current value
- A decrement button that subtracts 1 from the current value
:::
