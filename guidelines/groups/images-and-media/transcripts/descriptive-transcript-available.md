:term[Descriptive transcripts] are provided for prerecorded term:[audio] and term:[video content].

:::except-when
*The media is purely decorative.
*The media is already a media alternative for text and is clearly labeled as such.
*The visual track contains no information that is not already conveyed in the audio track (e.g., a "talking head" video where only the speaker is visible against a static background).
:::


:::ednote
* This includes actions, charts or :term[informative] visuals, scene changes, and on-screen :term[text],
:::
