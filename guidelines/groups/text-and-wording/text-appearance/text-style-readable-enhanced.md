The default/authored presentation of :term[text] style properties meets the enhanced @@ [values to be determined] for:
* Typeface
* Font size
* Font width
* Text decoration
* Letter spacing
* Capitalization
* End-of-line hyphenation

:::ednote
If you are aware of research in this area, especially involving non-Latin scripts, please email public-agwg-comments@w3.org.
:::
