A :term[mechanism] is available to move :term[keyboard focus] from any location in a :term[page]/:term[view] to the start of each primary section of the :term[page]/:term[view].

:::applies-when
A :term[page]/:term[view] includes two or more primary sections of content.
:::

:::except-when
:term[Keyboard focus] is located inside of a modal element and the :term[page]/:term[view] content outside the modal is inert.
:::

:::ednote
A new name for this provision may be proposed after there is consensus on the direction of the requirements.
:::
